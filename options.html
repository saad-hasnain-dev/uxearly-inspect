Uxearly Inspect

Fonts, colors, design tokens, code and images, in one inspector.

You’re all set

Open any website, then click the Uxearly Inspect icon in the toolbar or press Alt+Shift+I. Tip: pin the icon from the puzzle-piece menu so it’s always one click away.

How to use

  1. Open it on any page with the toolbar icon or Alt+Shift+I. Change shortcut
  2. Fonts hover text for its typography, pin it to copy its CSS or HTML, and download the font files a site uses.
  3. Colors pick any pixel on screen or browse the page palette.
  4. Measure hover for sizes, padding, margins and gaps, click to pin and see distances, hover text for letter widths and gaps, drag for a ruler.
  5. Tokens export the page's design system as CSS variables, JSON tokens or a Tailwind theme.
  6. Code select an element for its CSS, or a JSX component and CSS module on React / Next.js sites.
  7. Images download any image, background or SVG as Original, PNG, JPG, WebP or AVIF.
  8. Capture save a full-page or visible-area screenshot as PNG, JPG, WebP or PDF.
  9. Right-click any selected text and choose “Inspect font of …” to see its font details.

Image and font access on all sites Checking…

Files hosted on the same site as the page work out of the box, and so do most CDNs. A few CDNs block other sites from reading their files. Converting those images (PNG, JPG, WebP, AVIF), or listing fonts from stylesheets hosted there, needs permission to read them. Downloading an original image never needs it.

When granted, the extension still only reads a file when you open the Images or Fonts tab, download, or open image details. You can turn this off at any time.

High-resolution screenshots Checking…

Screen-quality captures work right away. HD (2×) and 4K captures re-render the page at a higher resolution, which needs Chrome’s debugging interface. While one runs, Chrome shows a “started debugging this browser” bar that closes when the capture finishes.

Used only during a capture you start, on that tab. Nothing is recorded or sent anywhere.

Privacy

  • No analytics, tracking or accounts. Nothing you inspect is sent anywhere.
  • The extension runs only on a tab after you click its icon or press its shortcut.
  • Preferences (theme, formats, panel position) are stored locally on this device.
  • All code, including the AVIF encoder, ships inside the extension. Nothing is loaded from the internet.

Respect copyright: only download images and assets you have the rights to use.
